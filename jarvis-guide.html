1. WHAT IS JARVIS

J.A.R.V.I.S. is a voice and text assistant for your PC. app.py is the brain (Python, Flask, speech, system control) and index.html is the face (a 3D hologram built with three.js). The app opens in its own desktop window, or in your browser if you start it with --browser.

Identity answer: "I am J.A.R.V.I.S., core operating intelligence for The Silent Exploit Base Project for learning." Say who are you to hear it.

  • Works by typing or by voice (microphone).
  • Speaks replies out loud, in a choice of voices.
  • Understands imperfect English and accents.
  • Remembers how you left it when you restart.
  • Greets you by time of day and plays a startup message.

Startup and greeting

On start Jarvis runs a diagnostics check in the terminal, says a random startup line (never the same twice in a row), then greets you: Good morning, afternoon, evening, or a late-night "Still grinding, bro?".

2. THE FRONTEND (3D INTERFACE)

What you see

  • 3D core in the centre: spinning shape with orbit rings, glow, particles and a floor grid. It pulses faster when the mic is on and when system load is high.
  • Watching eye that follows your cursor, blinks, and narrows with threat level. Plus many background eyes.
  • Floating 3D panels: title banner, CPU, RAM, threat, latency, FPS and battery gauges, info panel, intrusion log, direct-line chat panel, clock, and session stats.
  • Evil cursor (rotating ring and eye) with a bat trail. Clicking spawns a bat swarm. Ambient bat flocks fly across the screen.
  • Seasons: Winter, Spring, Summer, Autumn and Storm cycle automatically with snow, petals, embers, leaves or rain, and a big announcement each time.
  • Bat and eyes intro on startup. Click it to skip.
  • Danger levels 0 to 3 add warning stripes, red alarm vignette and camera shake.

4. LOCK JARVIS (PASSWORD)

YOUR JARVIS PASSWORD
2808
This page shows your real password. Keep this file private. Jarvis itself never stores the password in plain text, only a salted hash in ~/.jarvis/lock.json (file permission 600).

How to set it

Type this in the command box (typing is safer than saying it):

set password 2808

Also works: change password ..., new password ..., update password .... Minimum four characters. Spoken numbers count too: saying "two eight zero eight" matches 2808, because number words become digits and spaces are ignored.

How to lock

lock jarvislock screenlock the pcsecure yourself
  • lock jarvis locks only the assistant.
  • lock screen / lock pc locks the Linux session and also locks Jarvis (needs a password to be set).

What a locked Jarvis looks like

  • A full-screen red LOCKED overlay hides the panels and chat. Only the command box stays.
  • The input turns into a password field (masked).
  • Customize drawer, buttons and chips are hidden. Minimize is blocked.
  • Every input, spoken or typed, is treated only as a password attempt.

How to unlock

Just type or say 2808. You can also say unlock first, then the password, or the password is 2808. On success you hear "Password accepted. Welcome back." and the system screen unlocks too (via loginctl).

unlockunlock the screenunlock jarviscancel

Protection rules

  • 5 wrong tries gives a 30 second lockout.
  • The password is never written to chat history, the terminal log, or the recent-commands list (shown as ******).
  • The Whisper command-word hint is switched off while locked, so it does not distort the password.
  • Restarting does not unlock Jarvis.

5. VOICE: MICROPHONE AND SPEECH

Listening

  • Click MIC, press V, or click the core. The mic stays open between phrases, so the first words are not lost.
  • English only. Urdu, Hindi or Arabic script results are rejected.
  • Jarvis ignores his own voice (echo guard) and mutes the mic while he speaks.
  • Wake word is off by default. Set JARVIS_WAKE=1 to require "Hey Jarvis" (also hey, hi, ok, okay), with a 10 second awake window plus 8 seconds after each reply.

12. SMART UNDERSTANDING

Jarvis tries several layers before giving up, so rough English still works:

  • Mishearing fixes: "fire fox" becomes firefox, "volume app" becomes volume up, "why fi" becomes wifi.
  • Spelling repair: "volum" becomes volume.
  • Related words: "make sound big" becomes increase the volume.
  • Your own aliases in ~/.jarvis/aliases.json.
  • AI repair: the AI brain rewrites a mis-heard sentence into a known command (only safe commands or a web search).
  • Asks first when unsure: "Did you mean ...?"

Your own commands

Edit ~/.jarvis/commands.json to map a phrase to a shell command, for example "open my project": "code ~/projects".

13. SAFETY BUILT IN

  • Dangerous actions (shut down, restart, kill app, delete file, clear tasks or notes, lock screen guesses) always ask yes or no first, valid for 20 seconds.
  • Smart matching and AI repair can never map to delete, kill or shutdown.
  • File commands are limited to three folders and delete goes to the trash.
  • Protected system processes cannot be killed.
  • The web API only accepts requests from Jarvis' own page (127.0.0.1:5000).
  • Brightness never drops to black.
